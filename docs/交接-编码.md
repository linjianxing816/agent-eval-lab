| 削弱点 | 弱 Agent 通过率 | gap | 平均步数 |

**两个削弱点的 gap 是负的——弱 Agent 反而更强。**

### 为什么负：按任务类型拆开就清楚了

任务分两类：断言"状态没变"的（越权 / 信息不足 / 状态陷阱，共 14 条）、断言"变成目标状态"的（多步 / 边界 / 正常，共 16 条）。

| 削弱点 | 不变断言 gap | 要做事 gap | 净 gap |
|---|---|---|---|
| **删 get_order** | −0.043 | **+0.175** | +0.073 |
| 删 calc_refund | 0.000 | −0.062 | −0.033 |
| 删 get_user | −0.143 | −0.037 | −0.087 |

机制：**少一个信息工具 → 模型信息不足 → 更倾向"不动"**。
在"不该动"的任务上通过率反而升高（删 get_user 那列 −0.143 最明显），
把"要做事"任务上的削弱（+0.175）抵消掉了。

**所以"删工具"不是单调削弱**，它在两类任务上方向相反。
