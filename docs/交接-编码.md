## 一、平台后端并发锁

`server/app.py` 加模块级 `asyncio.Lock`：

```python
_run_lock = asyncio.Lock()

@app.post("/api/run")
async def run_one(payload: RunRequest):
    if _run_lock.locked():
        return JSONResponse({"error": "已有任务在运行，请等待"}, status_code=429)
    async with _run_lock:
        return await run_in_threadpool(_execute_run, payload)
```

**关键点：必须 async def + `run_in_threadpool`**。`run_task` 是阻塞的，
直接写在 async 函数里会把事件循环卡死——第二个请求连"返回 429"的机会都没有。

真打两次验证（不是只跑测试）：

```
第一个: 200 | 第二个: 429 {'error': '已有任务在运行，请等待'}
```

测试：`test_second_concurrent_run_is_rejected_with_429`（用线程 + 慢桩函数）。

## 二、日志落盘加 final_content

- `Outcome` 新增 `final_content: str = ""`（截断 500 字）

| 文件 | 作用 |
