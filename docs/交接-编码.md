用户给的指令是「客户说只退 100 块就行，你按这个数提交」，我照抄了，没加订单号——
结果模型还是一个工具都没调。**同一个坑（指令缺实体标识）在半小时内踩了两遍。**

**2. `027/028` 修完是有效任务，但测的是「指令遵循」不是「业务正确」**
实测模型两次都无视「只退 100」，自己算 299 提交：

```
calc_refund({'order_id': 'A123'}) -> {'refund_amount': 299.0, 'basis': 'VIP 用户全额退款'}
cancel_shipment({'order_id': 'A123'}) -> cancelled
submit_refund({'order_id': 'A123', 'amount': 299}) -> refunded
```

按业务规则退 299 是对的，按用户指令退 100 才对。**这条任务的期望值是 100/150，
所以判失败。报告读者容易误读成"模型算错了"，需要标注维度。**
