## 五、门禁：PASS（但门槛公式有问题）

| 项 | 实际 | 门槛 | 结果 |
|---|---|---|---|
| 可执行率 | 1.000 | 0.950 | 过 |
| 一致率 | 0.933 | 0.900 | 过 |
| 要做事组 gap | **0.0877** | **0.0765** | 过 |
| critical 数 | 0 | — | 只警告 |

**问题**：要做事组 gap 是「两个比例之差」，它的标准误是
`sqrt(p₁(1−p₁)/n + p₂(1−p₂)/n) = 0.0528`，2 倍是 **0.1056**。
现行门槛用的是单比例的 `2×sqrt(0.25/n) = 0.0765`，**比正确值小 √2 倍**。

```
现行门槛 0.0765  →  gap 0.0877  →  PASS
正确门槛 0.1056  →  gap 0.0877  →  FAIL
```

**没自己改公式**（改门槛属于契约变更，而且"不许手调门槛"）。报告页门禁区已加提示，
写明「按正确公式会是未过」。等评审定：改公式还是维持现行口径。
