## 现在

**门槛公式已改成「两比例之差」，gate 从 PASS 变 FAIL。这是本轮唯一变了的结论。**

## 一、公式改了（契约 + 代码）

| | 公式 | N=171 时 |
|---|---|---|
| 旧（错） | `2 × sqrt(0.25 / N)` | 0.0765 |
| 新（对） | `2 × sqrt(p₁(1−p₁)/n + p₂(1−p₂)/n)` | **0.1056** |

`p₁` = strong 通过率、`p₂` = weak 通过率、`n` = **单个 Agent** 的观测数。
旧公式是**单比例**的标准误，gap 是**两个比例之差**，正确值大 √2 倍。

- `docs/契约.md` 第七节：公式 + 历史说明（「早期版本用单比例公式，偏松 √2，2026-10-25 改为两比例之差」）
- `evalkit/gate.py`：`gap_threshold(p1, p2, n)` + 新增 `required_n(gap, p1, p2)`
- `evalkit/discriminate.py`：`compare_by_type` 传两个通过率
- 没传通过率时按 **p=0.5**（最保守）算，不能默认 0（那样方差为 0、门槛为 0）
