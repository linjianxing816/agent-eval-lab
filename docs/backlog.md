## 四、判断"值不值得加"的三条标准

加任何东西之前，先过这三条：

1. **它回答的问题，是基准版回答不了的吗？**
   如果是"同一个问题换个说法"，不加。

2. **它能产出数字吗？**
   加完只能说"我实现了 XX"，不能说出"XX 从 A 变成 B"，不加。

3. **它会不会让已有的结论失效？**
   比如加了多 Agent 协作，"越权检测"的语义就变了，前面的实验要重跑。会，就不加。

**三条全过，才写进计划表。**
